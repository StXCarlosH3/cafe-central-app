# cafe-central-app# Café Central - Sistema de pedidos

## Descripción
Aplicación para organizar y administrar los pedidos de una cafetería, facilitando el registro de productos y el seguimiento de las órdenes.

## Problema que resuelve
Permite llevar un mejor control de los pedidos, evitar confusiones y mejorar la atención a los clientes.

## Funcionalidades principales
- Registro de pedidos.
- Consulta de productos.
- Seguimiento del estado de los pedidos.
- Organización de las actividades del equipo.
